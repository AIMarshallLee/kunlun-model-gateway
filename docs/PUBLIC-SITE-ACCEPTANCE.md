# 商业公共站点：本地验收记录

范围：商业 PRD 的公共入口与接入说明，不代表整个商业站、正式政策或真实收款完成。

## 本次实现

- `managed_gateway` 的 `/` 为英文首页，可切换中文；原 BYOK/测试模式首页保持原控制台。
- `/console` 继续使用现有客户控制台；验证邮箱、重置密码仍进入账户页面。托管结账返回 `/console`，返回本身不能入账。
- `/public/catalog` 从数据库读取当前有效零售价，仅公开模型、售价版本、输出上限和公开运营配置；不公开供应商密钥、成本或平台预算。
- `/api-guide` 提供当前站点地址及已列模型的 curl/Python 示例、OpenCode 接入说明、幂等恢复与错误说明。示例不自动执行；OpenCode 仍须安装仓库内的幂等插件。
- `/service-info` 明确数据、退款处理和支持边界。正式条款链接缺失时明确提示，不拿说明页替代运营主体确认的法律条款。
- 公共页面默认英文，语言经 URL 保持；同源脚本/样式，无外部字体、分析脚本或浏览器持久化。价格获取失败清空表格，不缓存旧价格或伪造可购买状态。
- 商业控制台移除客户必须自带模型 Key 的引导，提供已列模型测试入口；测试可能消费额度。完整控制台英文体验未完成。

## 已执行检查

本次本地全量：392 项 Python 测试通过，分支覆盖率 82%；TypeScript 类型检查和 37 项测试通过。存在一项既有 Starlette/httpx 弃用警告。两份前端 JavaScript 语法检查与 `git diff --check` 通过。

新增 6 项 Python 回归覆盖路由/验证链接、当前数据库价格与下架、公开字段不泄密、旧模式隔离、脚本不持久化/注入 HTML、政策链接协议及凭据限制、购买返回路径。

真实浏览器检查针对 `127.0.0.1:8795` 的独立 SQLite 测试服务，无供应商凭据，无真实支付、用户账号或模型外呼：

1. 桌面首页、中文切换、接入指南及复制反馈正常。
2. 隔离 Chromium 的 390×844 视口：首页、中文指南、服务说明无横向溢出；英文→中文→英文保持标题词间分隔。
3. 中文导航保留 `lang=zh`；生成的 curl 通过 shell 语法检查，Python 通过 AST 解析，均未执行模型请求。
4. 测试环境明确标为测试价格/不能真实购买；政策链接与支持联系人未配置时正确提示。
5. 控制台商业模式不要求 BYOK；目录请求模拟 503 后清空价格并提示不可用；检查期间无页面脚本错误。
