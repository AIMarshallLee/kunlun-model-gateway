# 自有工具接入样例与验收

范围：PRD §4.6 的可运行接入样例。不是完整公众号应用，不是指定真实套壳产品的集成，也不是已上线或真实付费证据。商业中转目标保持不变：使用本站 Key 和本站调用额度，平台供应商 Key 不交给客户端。

## 运行

从仓库根目录使用已安装项目依赖的 Python；样例依赖现有 httpx，不新增 SDK。它随源码交付，不作为独立 SDK 或 wheel 包发布。

1. 把 `KUNLUN_TOOL_ORIGIN` 设为经过你核验的本站 HTTPS 根地址，不能包含 `/v1`、查询串或用户名密码。该地址是可信部署配置，不接受终端客户传入任意 URL。
2. 通过自己的受控运行环境注入 `KUNLUN_TOOL_API_KEY`（本站 Key），不放入命令参数、源码或聊天。不使用供应商 Key。
3. 为一个业务任务保留稳定且不含个人信息的 operation ID。可预览：

```sh
.venv/bin/python examples/own_tool_gateway.py --operation-id sample-draft-001
```

默认预览：不读 Key、不读 stdin、不联网、不写文件。准备执行时，将 [合成请求](../examples/draft-request.json) 中模型替换为当前可售目录中的 ID；使用自己的授权素材需另外核对数据边界。

```sh
.venv/bin/python examples/own_tool_gateway.py --operation-id sample-draft-001 --execute < examples/draft-request.json
```

`--execute` 会调用模型，可能收费；本轮没有执行任何真实模型调用。模型不存在、余额不足等由网关拒绝，样例不会充值或更换供应商。CLI 的输入上限 1 MiB、输出读取上限 10 MiB，是样例保护值，不替代服务端限额。HTTP timeout 是单次网络读写/连接的等待限制，不是额外的网关总任务截止时间；网关自己的总调用期限仍生效。

CLI 输出 JSON：`output` 是回答或 SSE 事件数组，仅返回给调用工具；不自动写盘。调用方不得把 stdout 接入共享日志或遥测。SSE 会先在内存中收齐再输出，不实现逐字展示。`tools`、`tool_choice` 和工具消息通过 stdin 请求透传；返回的工具调用不会自动执行，工具权限和人工审核属于业务应用责任。

## 恢复规则

| 结果 | 调用方处理 |
|---|---|
| `delivery=complete` | 完整回答 / SSE DONE 与查询到的 `settled` 同时成立；仍需业务人工审核 |
| `delivery=needs_review` | 可能有部分回答，也可能已扣费；不得自动重发 |
| 重复任务 409 | 查询原任务，不重放原答案；平台不保存回答正文 |
| lookup 404 或查询失败 | 不证明未受理或未扣费；保留原 ID，稍后查询/联系支持 |
| 待对账 / 未完成 | 保持原 ID，不换供应商、不自动新建任务 |

只查询原任务，不读素材、不发送新的模型任务：

```sh
.venv/bin/python examples/own_tool_gateway.py --operation-id sample-draft-001 --lookup
```

查询使用 `POST /v1/requests/lookup`，这是只读查询接口；幂等 ID 放请求头，避免出现在 URL 日志中。首次调用成功后立即执行一次查询，不持续轮询。网络错误、HTTP 错误、重定向或解析失败均不自动重试模型请求。CLI 成功返回 0，需处理的结果返回 2；查询返回 0 只表示拿到元数据，不代表业务已成功。

只有人工明确决定新建业务任务，才换新的 operation ID；同一 ID 不用于修改输入后重新生成。真实业务系统负责持久化任务 ID、人工审核决定和客户授权保存的交付稿，本样例不新增数据库或内容日志。

## 本地验收证据边界

`tests/test_own_tool_example.py` 使用实际 managed gateway 路由、数据库与账本，供应商、支付、邮件均是隔离模拟：

- 一次调用 + 重复任务：仅一次供应商请求及一次客户扣费；重复任务只能获得元数据。
- 余额不足：402，零模型外呼。
- SSE 完整 DONE 与最终用量：结算后可交付；断流：待对账，不自动切换。
- 模型已结算但客户端丢失回答：只查原任务，保留已结算状态，不重复扣费。
- 工具调用原样返回，但不执行工具。
- HTTPS 根地址验证、不跟随重定向、限制读取大小；预览不读取 Key 或素材。

现有网关租户隔离测试继续负责服务端所有权边界。本样例不宣称验收任何第三方客户端版本。真实自有工具项目尚未指定，真实支付、供应商、预发布环境和生产发布仍须单独验收。

回滚：移除本样例和相关文档链接即可；未改变网关接口、数据库、计费或生产配置。
