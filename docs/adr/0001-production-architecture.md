# ADR-0001：生产架构与外部依赖门禁

- 状态：候选生产基线（未代表已上线）
- 日期：2026-08-23

## 决策

采用模块化单体：一个 FastAPI 网关、一个 PostgreSQL 数据库，外置 Caddy TLS 反代；邮件、验证码、内容安全、模型供应商和支付桥均为显式适配器。Caddy 使用固定私网地址覆盖专用客户端 IP 头，应用仅信任配置的精确代理 CIDR，Uvicorn 不解析任意公网转发头。OpenCode 只作为受控编排层，不能成为客户直接调用的公共 API。

生产公开注册、真实上游和真实支付必须分别满足配置、迁移、回调验签、限额和人工验收门禁。任何缺少真实凭据、域名 DNS、供应商联调或合规材料的环境都保持关闭，而不是用测试适配器冒充上线。

## 原因与取舍

模块化单体降低首个垂直产品的运维复杂度，同时通过服务接口隔离未来替换 OpenCode、模型供应商或支付桥。PostgreSQL 提供事务、锁和审计台账；Caddy 负责证书续期、HTTPS 与请求体上限。代价是单体发布需要完整回归，且外部依赖故障必须由网关显式降级、停止或人工接管。

## 不在本决策中的事项

不建设共享账号、低价 Key、匿名充值、无限量承诺或面向公众的通用 Token 中转平台；不把本地测试、Docker compose 或通过预检等同于真实客户上线。
