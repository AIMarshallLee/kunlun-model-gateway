# 双进程 HTTP 负载与硬停止恢复验收

本批是源码级隔离验收工具，无业务 schema 变更。不是 Vercel 实际部署、真实供应商压测、长时容量认证或正式收款证明。

## 自动化入口与防误用

在可丢弃 PostgreSQL 16 上先执行 `scripts/ci_postgres_gate.sh`，再运行：

```sh
.venv/bin/python scripts/verify_runtime_postgres.py
```

必须提供 `KUNLUN_CI_ISOLATED_DATABASE=kunlun-ci-disposable` 和隔离实例的 `KUNLUN_RUNTIME_DATABASE_URL`。URL 只接受 `postgresql+psycopg`、`127.0.0.1`、数据库 `kunlun_ci`、角色 `kunlun_runtime`，不接受连接 query 或 libpq service／hostaddr／options 覆盖。不得填写生产凭据或把本地端口映射到真实数据库。

工具只在当前迁移后的合成库新增独立测试账户、额度和请求。它要求原 CI 财务测试已经建立当天的冻结预算。两个 API 子进程使用独立绑定的 loopback socket 和独立连接池，共用真实 PostgreSQL runtime 角色；父进程保有 socket，避免端口竞争或把测试 Key 发给其他本地服务。停止只针对自己创建的子进程句柄，不扫描或停止现有服务。

模拟运行入口为 `tests/runtime_ci_fixture.py`：显式替换模型 transport 和 Vault、清除继承的业务配置；支付、公共注册与真实上游均不启用。它有只返回实例 ID、调用计数和阻塞状态的测试接口，不能用于部署。CI 另查该测试入口没有进入 Vercel 应用镜像；安装后的应用包不能单独运行依赖此文件的源码验收脚本。

## 场景与硬通过条件

| 场景 | 检查 |
| --- | --- |
| 有限并发负载 | 8 个请求线程，两个 API 进程轮流接收；替换前后各 10 批、每批 8 个请求；160 个请求全部 HTTP 200，输出实测 P50／P95／最大耗时 |
| 余额不足 | 未充值合成账户返回 402，两个进程的模拟上游计数均不增加 |
| 跨实例幂等 | 16 次同租户同幂等键并发提交，只允许 1 次 200、15 次 409 |
| 租户隔离 | 另一个租户使用自己的 Key 查询已知请求 ID，返回 404 |
| 硬停止 | 等待模拟上游确认进入处理，并检查预授权已落库；直接 kill 该 API 子进程，不靠优雅关机代码补记结果 |
| 存活与替代实例 | 另一个进程及新启动实例都拒绝重放已完成／在途幂等键，替代实例的上游计数保持零 |
| 租约过期 | 只调整该合成请求的时间戳，再运行实际 maintenance 事务；请求转待对账，不能自动释放或重新外呼 |
| 财务核验 | 162 个逻辑请求 = 161 次结算 + 1 笔待对账；每次成功客户扣 6 microUSD、上游成本 2 microUSD；两者是合成计价，不是售价建议 |
| 恢复后预算 | 钱包非负、可用加占用加已扣等于初始额度；客户未知占用保留，平台占用等于该日所有未结清预授权之和；进程配置不能抬高原有数据库日上限 |
| 账本与 attempt | 双式账本每笔平衡；161 个已知成功 attempt；被硬停止请求可能来不及记录 attempt，因此仍须按未知费用处理，不能推论没有上游成本 |

输出不包含提示词、响应正文、客户 Key、数据库口令或内容指纹。测试产生的所有财务记录留在一次性数据库中；子进程退出时回收，CI 服务结束时销毁合成数据库。本工具不会删除、覆盖或恢复已有数据库。

## 证据的覆盖范围

本地隔离首轮有效结果：160 个普通并发请求全部通过，161 笔结算、1 笔未知占用保留；替代进程未重复外呼。数值延迟受机器、CI runner、连接池和模拟 transport 影响，以对应提交的执行输出为准，不转换成商业 SLA 或用户容量。

仍需实际验收：真实供应商耗时和 SSE 中断、长时间持续负载与不同并发档位、Vercel 的实例扩缩容／请求时限／真实重部署、目标数据库连接额度、边缘限流与 WAF、真实支付和退款。这里只替换同一源码版本的本地进程，不证明跨版本迁移或生产回滚安全；真实发布仍需明确批准和受保护环境。

## 回滚

本批只增加测试工具、CI 与文档，不改业务状态机或迁移 head `0017_chargeback_returns`。撤回测试无需降级数据库。真实事故仍须暂停新流量、保留账本与未知占用，并按[恢复验收](RESTORE-ACCEPTANCE.md)核对，不允许删账或自动释放未知费用。
